# WRC Website

Welcome to the **WRC Website**! This project is dedicated to providing information about the World Rally Championship (WRC). The website features a clean design and various sections to explore the thrilling world of rally racing.

## Project Files

- **index.html**: The main HTML file for the homepage of the WRC website.
- **carousel.html**: A page featuring a carousel for showcasing rally images and videos.
- **data.html**: A page containing additional data and statistics related to the WRC.
- **style.css**: The main CSS file for styling the website.
- **custom.js**: JavaScript file for custom functionalities and interactivity.
- **index.js**: JavaScript file for handling scripts related to the index page.
- **pics/**: A directory containing images used throughout the website.
- **Early Era/**: A directory that may contain historical data or images from the early years of WRC.
- **carousel/**: A directory for any files specifically related to the carousel feature.
- **2024-01-01 20-10-18.mkv**: A video file related to the WRC.
- **PURE SOUNDS! Group B Rally Cars.mp4**: A video showcasing Group B rally cars.
